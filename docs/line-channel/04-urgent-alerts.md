# Phase 5–6 — ประกาศด่วน (urgent alert) + ส่งเข้า LINE

> **Phase 5** (v5.79.0, GAS 5.73.0) = สร้าง/ปิดประกาศจากหน้า admin ได้ · ✅ ใช้งานจริงแล้ว
> **Phase 6** (v5.81.0, GAS 5.74.0) = ติ๊กเพิ่มเพื่อ broadcast ประกาศนั้นเข้า LINE ด้วย

## ประกาศด่วนคืออะไร / ไปถึงผู้ใช้ยังไง

| ช่องทาง | ใครได้รับ | ช้า/เร็ว | ต้นทุน |
|---|---|---|---|
| **ในแอป** (หลัก) | ทุกคนที่เปิดแอป | ภายใน ~5 นาที (service worker poll) | ฟรี |
| **LINE broadcast** (เสริม) | ผู้ติดตาม LINE OA | ทันที | **กินโควตา** |

> ประกาศในแอปคือช่องทางหลักเสมอ — LINE เป็นตัวเสริมให้ถึงเร็วขึ้น
> **ถ้า LINE ส่งไม่สำเร็จ ประกาศในแอปยังส่งออกปกติ** (ล็อกไว้ด้วยเทสต์ `test/gas-line-broadcast.test.js`)

## ⚠️ โควตา — อ่านก่อนกดส่ง

- **1 broadcast = 1 ข้อความ × จำนวนผู้ติดตาม** (ผู้ติดตาม 100 คน = ใช้ 100 ข้อความ)
- แพลนฟรี = **300 ข้อความ/เดือน และเป็นเพดานตายตัว** (หมดแล้วส่งไม่ได้จนขึ้นเดือนใหม่)
- หน้า admin จะ**แสดงโควตาคงเหลือ + ประเมินยอดที่จะใช้** ตอนติ๊กช่อง LINE และถามยืนยันอีกครั้งก่อนส่ง
- ตัวเลขผู้ติดตามที่ LINE รายงานเป็นข้อมูล**ย้อนหลัง 1 วัน** — ถ้ายังไม่มีข้อมูล ระบบจะบอกว่า "ไม่ทราบ" (ไม่ใช่ 0)

## ตั้งค่าครั้งเดียว — ใส่ token ใน GAS

จำเป็นเฉพาะเมื่อจะใช้ LINE broadcast (ถ้าไม่ใส่ ประกาศในแอปยังทำงานปกติ)

1. เปิด GAS editor (ตัวที่ deploy `gas-complete.js`)
2. เมนู **⚙️ Project Settings → Script Properties → Add script property**
3. ใส่:
   - **Property**: `LINE_CHANNEL_ACCESS_TOKEN`
   - **Value**: Channel access token (long-lived) จาก LINE Developers Console
4. Save

> 🔒 **ห้ามวาง token ลงในไฟล์โค้ดเด็ดขาด** — repo นี้เป็น public · แบบแผนเดียวกับ `SUPABASE_SERVICE_KEY`
> รายละเอียดที่เก็บ secret ทั้งหมด: [`SECRETS.md`](SECRETS.md)

## Deploy GAS (ทุกครั้งที่แก้ `gas-complete.js`)

1. copy `gas-complete.js` ทั้งไฟล์ → วางทับใน GAS editor → **Save (Ctrl+S)**
2. **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
3. ทำ **ทั้ง 2 deployment** (Admin + Analytics)
4. ตรวจที่หน้า admin → **ตั้งค่า → ตรวจเวอร์ชัน** ต้องขึ้น **GAS v5.74.0 ✅ ตรงกับโค้ด**

> **Run ≠ Deploy** — กดปุ่ม Run ในเอดิเตอร์ไม่ทำให้เว็บใช้โค้ดใหม่ ต้อง Deploy เท่านั้น

## วิธีใช้งาน

1. หน้า admin → แท็บ **📢 ประกาศด่วน** → **สร้างประกาศ**
2. กรอกหัวข้อ + รายละเอียด (จำเป็น), เลือกความรุนแรง, ใส่ชื่อยา/สิ่งที่ต้องทำ (ถ้ามี)
3. ถ้าต้องการส่ง LINE ด้วย → ติ๊ก **"ส่งเข้า LINE ด้วย"** แล้วดูโควตาที่ขึ้นมา
4. กด **ส่งประกาศ** → ยืนยันอีกครั้ง (กล่องยืนยันจะบอกยอดโควตาที่จะใช้)
5. ผลลัพธ์:
   - `✅ ส่งประกาศ + LINE แล้ว` = สำเร็จทั้งคู่
   - `✅ ประกาศในแอปแล้ว — แต่ส่ง LINE ไม่สำเร็จ: …` = ประกาศออกแล้ว แต่ LINE พลาด (ดูเหตุผลในข้อความ + Audit Log)

## แก้ปัญหา

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN not set` | ยังไม่ได้ใส่ Script Property (ขั้นตอนด้านบน) หรือใส่แล้วยังไม่ Deploy ใหม่ |
| ส่ง LINE ไม่สำเร็จ HTTP 429 | โควตาเดือนนี้หมด — รอเดือนใหม่ หรืออัปเกรดแพ็กเกจ |
| ส่ง LINE ไม่สำเร็จ HTTP 401 | token ผิด/หมดอายุ → ออกใหม่ที่ LINE Developers แล้วอัปเดต Script Property |
| ตรวจโควตาไม่ได้ แต่ยังส่งได้ | ปกติ — ระบบไม่บล็อกการส่ง เพียงแต่ไม่รู้ยอดล่วงหน้า |
| ประกาศไม่ขึ้นในแอป | คนละเรื่องกับ LINE — เช็คว่า deploy GAS ครบทั้ง 2 ตัว และรอรอบ poll ~5 นาที |
